Admin Panel Password

Admin Panel unlock করতে তোমার নির্ধারিত passcode লিখো। এই password শুধু এই Admin Panel-এ লাগবে; মূল অ্যাপ খুলতে কোনো password লাগবে না।

Passcode source code-এ রাখা নেই। Supabase server-side hash দিয়ে যাচাই করে এবং পাঁচবার ভুল দিলে ১৫ মিনিটের lockout দেয়।

৩. একসঙ্গে অনেকগুলি প্রশ্ন Paste করুন

একটি প্রশ্নের পরে পরের প্রশ্ন লিখুন। Q1 / প্রশ্ন ১ / 1. দিয়ে প্রশ্ন শুরু করতে পারেন। বিকল্প A–H পর্যন্ত দেওয়া যাবে। সঠিক উত্তর ও ব্যাখ্যা লিখুন। JSON array-ও গ্রহণ করা হবে।

প্রশ্নের সংখ্যার জন্য অ্যাপে আলাদা কোনো নির্দিষ্ট cap রাখা হয়নি। Supabase insert ২৫০টি করে batch-এ হবে; খুব বড় import-এর ক্ষেত্রে project limits ও API request limits প্রযোজ্য হতে পারে।
